# auction-action

**옥션&액션** — 실시간 입찰·자동 낙찰·모의 결제·정산 경매 프로토타입.

등록 → 실시간 입찰 → 시간 만료 자동 낙찰 → 모의 결제 → 정산까지 이어지는
상태 기반 경매 웹 프로토타입입니다. 서버나 빌드 도구 없이 브라우저에서 바로 동작하며,
데이터는 `localStorage`에 저장됩니다. 딥 버건디 배경과 심장박동 애니메이션으로
경매의 긴장감을 강조합니다.

## 로컬 실행

```bash
npm start
```

브라우저에서 <http://localhost:4173> 접속.

> ES 모듈을 사용하므로 `index.html`을 파일로 직접 열지 말고 위 서버로 실행하세요.
> 포트를 바꾸려면 `PORT=5000 node server.js` 처럼 지정합니다. (Windows PowerShell: `$env:PORT=5000; node server.js`)

## 핵심 흐름

```
active ──(마감)──▶ won(결제 대기) ──(모의 결제)──▶ paid(정산 대기) ──(정산 완료)──▶ settled
   │                     │
   └──(입찰 없음)──▶ failed ◀──(결제 기한 만료)
```

- **봉인 입찰(sealed)** — 참가자끼리 금액을 볼 수 없고, 마감 시 최고가가 자동 낙찰됩니다. 마감 후 모든 금액과 순위가 공개됩니다.
- **선착순(first)** — 가장 먼저 입찰한 사람이 그 가격으로 **즉시 낙찰**됩니다.
- **하향 경매(dutch)** — 입찰자가 없으면 시작가의 **0.5%씩**, 설정한 주기마다 가격이 자동 하락합니다.
  최저가에 도달하면 더 내려가지 않으며, 원하는 시점의 현재가를 수락하면 즉시 낙찰됩니다.

### 자동 처리

- 1초 티커가 마감 시각을 감시하고 `processExpired()`로 자동 낙찰/유찰 처리합니다.
- 낙찰 후 24시간이 지나면 결제 기한 만료로 거래가 취소됩니다.
- 판매 수수료는 낙찰가의 **5%**이며, 구매자는 낙찰가만 결제합니다.
- 결제 완료 시 `정산 장부`에 `정산 대기` 항목이 생성되고, 운영자 역할의 **정산 완료 처리** 버튼으로 `정산 완료` 상태가 됩니다.

## 화면

| 경로 | 설명 |
| --- | --- |
| `#/` | 히어로·실시간 입찰 피드·진행 중 경매·지난 결과 |
| `#/new` | 상품 이미지, 가격, 마감 시각(확인 버튼으로 일정 검증), 등록자, 입찰 방식 설정 (실시간 미리보기) |
| `#/a/:id` | 입찰 패널, 카운트다운, 입찰 기록, 낙찰 결과·모의 결제·영수증 |
| `#/settlements` | 결제 대기 거래, 정산 요약, 판매자별 정산 장부 |

## 데모 기능

- **라이벌 봇**: 헤더에서 켜고 끌 수 있습니다. 봉인 입찰에만 자동 참여하며,
  내가 입찰한 경매에는 추가 입찰하지 않습니다.
- **프로필**: 우측 상단에서 입찰자 이름·연락처·기본 결제 수단을 변경합니다. 입찰 시 자동으로 채워집니다.
- **멀티 탭 실시간 동기화**: 같은 브라우저의 다른 탭에서 입찰하면 `BroadcastChannel` + `storage` 이벤트로
  목록·피드·토스트가 갱신됩니다.
- **데모 초기화**: 푸터의 `데모 초기화`로 시드 데이터를 다시 만듭니다.
- **이미지 업로드**: 최대 12MB 이미지를 캔버스에서 1100px JPEG로 자동 압축해 저장합니다.
- **모의 결제**: 카드 / 계좌이체 / 카카오페이 / 액션 포인트. 실제 청구는 없습니다.

## 빠른 체험 시나리오

1. 홈에서 **빈티지 35mm 필름 카메라**를 열고 이름·연락처·금액을 입력해 봉인 입찰합니다.
2. 마감(약 3분)까지 기다리면 자동 낙찰되고, 결제 버튼이 나타납니다.
3. 카드 정보를 입력해 모의 결제를 완료하면 영수증과 정산 장부가 생성됩니다.
4. **정산 센터**에서 `정산 완료 처리`를 눌러 판매자 정산까지 마무리합니다.
5. `#/new`에서 선착순 경매를 만들면 첫 입찰 즉시 낙찰되는 흐름을 바로 확인할 수 있습니다.

첫 실행 시 결제·정산을 바로 체험할 수 있도록 **이미 낙찰된 라이카 M3 데모 건**이
`결제 대기` 상태로 준비되어 있습니다. (정산 센터 → 결제하기)

## 알려진 한계 (프로토타입)

- **서버가 없습니다.** 브라우저를 완전히 닫으면 1초 티커도 멈추므로, 자동 낙찰은
  페이지가 열려 있을 때(또는 다시 열었을 때) 처리됩니다.
- 로그인·권한 검증이 없고 프로필은 브라우저 로컬에만 존재합니다. 결제는 모의 처리입니다.
- `localStorage` 용량(약 5MB)을 공유하므로 이미지를 많이 등록하면 한계에 도달할 수 있습니다.
- 같은 브라우저의 모든 탭은 동일한 사용자(프로필)를 공유합니다. 여러 사용자 시뮬레이션은
  라이벌 봇 또는 시드 데이터로 대신합니다.

실서비스로 확장하려면 서버 측 경매 상태 머신, 인증, WebSocket, 실제 PG 연동,
DB 트랜잭션 기반 정산 원장이 필요합니다.
